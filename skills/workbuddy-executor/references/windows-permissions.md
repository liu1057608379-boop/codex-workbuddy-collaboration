# 权限与空会话初始化

本公开版本不携带任何个人机器的权限结论。使用现有合法配置，不默认要求用户关闭沙箱或“全部允许”。权限拒绝时核具体工具错误与资源，输出脱敏结论，由用户处理必要授权；不导出登录字段、规则全集或原生数据库。

只读 SQLite 连接仍可能访问 WAL/SHM 侧车文件；出现历史校验失败时不要立即认定数据库损坏。若领取已记为 working 但锁清理错误导致正文未返回，保留原编号，核实际轮次和副作用，通过兼容 Gateway 的受控恢复处理。不能手改数据库、删 claim 或伪造 report。

空会话界面模型选择可能尚未持久化。先展示会话与模型供用户确认；必要时在正常界面选择该模型并发送“仅回复就绪，不读文件、不执行命令”。这不是业务派工。核实际回复的模型与 sessionId 再派正式任务，不通过远程 model 参数覆盖。模型不符则停止未开始的业务任务。

busy、心跳、动画和领取记录都不能证明本轮正文已交付；核当前 attempt 的 progress 或真实工具活动。只在实际错误需要时查最少原生记录，不读取凭据或输出完整历史。
